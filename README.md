## 🌐 GitHub Pages

The website is published directly from this repository using GitHub Pages.

**Website URL:**  
https://bbanda.github.io

To deploy changes:

1. Clone or fork this repository.
2. Make your changes.
3. Commit and push them to GitHub.
4. Configure GitHub Pages under repository Settings → Pages.
5. Select the appropriate deployment branch and folder.

GitHub Pages will automatically publish the website.
